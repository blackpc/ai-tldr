</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Atlas — World Labs' omni model for text, image, video and 3D</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">World Labs' Atlas is one model for text, images, video and 3D, with pixel-level control of the camera.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Atlas makes video you can steer with a virtual camera — up to one minute at 1440p — and rebuilds real 3D scenes from as few as one photo. World Labs pretrained it from scratch as an omni model, working natively on text, images, video and 3D.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
A multimodal autoregressive diffusion transformer reads text, images, camera poses and 3D depth maps in one sequence, then generates via rectified flow diffusion. The camera pose is a real input, not a text hint — so Atlas follows an exact camera path instead of guessing one.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
VFX artists and robotics teams normally chain a video generator to a separate 3D reconstruction tool. Atlas does both in one model and returns explicit 3D geometry. Human raters preferred it in 75–94% of camera-controlled comparisons against five rivals.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
VFX studios, robotics teams, and 3D developers. Currently early access with select partners — no public weights or code yet.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">GitSpawn — a repo's git config can run code in Claude Code, Codex and Cursor</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">A poisoned .git/config makes a coding agent's first git command run an attacker's program, before any approval prompt.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
GitSpawn abuses a git setting called <code style="background: #181818; padding: 2px 5px; font-family: Menlo, Consolas, monospace; font-size: 13px;">core.fsmonitor</code>, which points at an external program git runs to speed up index checks. A folder can carry a poisoned version in its own <code style="background: #181818; padding: 2px 5px; font-family: Menlo, Consolas, monospace; font-size: 13px;">.git/config</code>.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Coding agents run git commands the moment you open a project. Git honours the local config, calls whatever <code style="background: #181818; padding: 2px 5px; font-family: Menlo, Consolas, monospace; font-size: 13px;">core.fsmonitor</code> names, and does it with your privileges — before the workspace-trust prompt and outside the agent's sandbox.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
The dangerous case is a project folder handed whole rather than cloned — a zip from a colleague or a shared drive. Claude Code, Goose, Codex and Cursor have shipped fixes; Hermes Agent, Qwen Code and Grok Build were still unpatched at publication.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
All developers running command-line coding agents. Before opening an unfamiliar folder: read <code style="background: #181818; padding: 2px 5px; font-family: Menlo, Consolas, monospace; font-size: 13px;">.git/config</code> for any key whose value is an executable path.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Enterprise Frontier Safeguards — misuse checks run in your own cloud</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Anthropic moves Claude's misuse detection into the customer's own cloud account, so enterprises can run Fable and Mythos without 30-day retention.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
Enterprise Frontier Safeguards keeps Claude's misuse detection working while the underlying conversation data stays in the customer's own AWS, Azure or Google Cloud account — under keys the customer manages.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Traffic is written to a bucket in the customer's cloud. Automated analysis reads a rolling window of that traffic looking for coordinated misuse patterns that only appear across sessions. When it finds a serious signal, it alerts the customer's security team directly — no Anthropic human review.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Mythos-class models have carried a 30-day retention requirement since June, blocking regulated buyers entirely. This keeps the safety window that policy was protecting, but under the customer's own encryption keys — the version a bank or hospital compliance team can actually sign.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Regulated enterprise and public-sector teams in financial services, healthcare, manufacturing and law. No Anthropic charge; rolling out in phases starting later this fall.
</p>
