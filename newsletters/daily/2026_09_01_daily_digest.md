<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">ChatGPT is a search engine under EU law — DSA's strictest tier now applies</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">ChatGPT becomes the first generative AI chatbot to fall under the DSA's toughest rules.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The <a href="https://digital-strategy.ec.europa.eu/en/news/commission-designates-chatgpt-reddit-roblox-under-digital-services-act" style="color: #f7ff00;">European Commission designated ChatGPT</a> a Very Large Online Search Engine under the Digital Services Act on August 31, 2026. It is the first generative AI chatbot to land in the DSA's strictest tier — OpenAI has four months to comply.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
The Commission calls ChatGPT a "hybrid service" that meets the search engine definition because it can respond to user queries including by searching the web. ChatGPT declared 159 million monthly active EU users, well over the 45 million designation threshold.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Designation brings real duties: annual systemic risk assessments, independent audits, a public ad repository, and vetted researcher access to platform data. Penalties reach 6% of global annual turnover for non-compliance.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Policy teams, researchers studying AI systems, and anyone shipping AI products in the EU.
</p>

<strong style="color: #f7ff00;">What is it?</strong><br>

It fires when a model probes or tries to break out of a sandbox, blocking the action before the tool call runs and alerting a human.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>

</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Claude sessions stolen by infostealer malware — Anthropic signs users out</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Infostealer malware on user machines copied live Claude session cookies, so attackers drained paid usage without ever entering a password.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
<a href="https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-warns-infostealer-malware-is-hijacking-claude-sessions-to-drain-usage/" style="color: #f7ff00;">Anthropic emailed affected users</a> that infostealer malware on their own computers copied their active Claude login sessions. Attackers then replayed those sessions to consume victims' paid usage. Claude itself was not breached — the malware came from elsewhere on the machine.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
Malware families like Vidar, LummaC2, and Atomic Stealer sweep infected machines for browser cookies. A stolen session cookie is already authenticated, so replaying it bypasses the login screen — and with it, two-factor authentication. Anthropic revoked sessions, deleted saved payment methods, and refunded unauthorized charges.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Signing out stops the stolen sessions, but it doesn't remove the malware — so the next login can be stolen the same way. An AI subscription is now a credential worth stealing, and a session cookie is the softest part.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Claude subscribers and security teams managing AI tool access: run a full malware scan before logging back in, then change your password with 2FA enabled.
</p>

<h2 style="margin: 0 0 8px; font-size: 24px; font-weight: 800; color: #f5f5f0; line-height: 1.2;">Codex CLI 0.152.0 — the planning tool is now off by default</h2>

<p style="margin: 0 0 20px; font-size: 15px; color: #8a8a85; line-height: 1.5;">Codex CLI 0.152.0 turns the planning tool off by default and tightens how MCP tools return output.</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">What is it?</strong><br>
The <a href="https://github.com/openai/codex/releases/tag/rust-v0.152.0" style="color: #f7ff00;">planning tool is disabled by default</a> in Codex CLI 0.152.0. Anyone who relied on the agent writing plans must opt back in with <code style="font-family: Menlo, Consolas, monospace; color: #f7ff00;">tools.update_plan.enabled = true</code>. Vim mode also gains <code style="font-family: Menlo, Consolas, monospace; color: #f7ff00;">/</code> and <code style="font-family: Menlo, Consolas, monospace; color: #f7ff00;">?</code> search inside drafts with highlighted matches.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">How does it work?</strong><br>
A per-tool <code style="font-family: Menlo, Consolas, monospace; color: #f7ff00;">output_token_limit</code> caps what any individual MCP tool can return. Cloud task requests now reject untrusted backend URLs and refuse redirects, protecting saved credentials.
</p>

<p style="margin: 0 0 16px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Why does it matter?</strong><br>
Long agent runs get practical fixes: automatic approval reviews preserve user instructions across history compaction, and rate-limit banners now offer direct actions for checking usage and managing credits.
</p>

<p style="margin: 0 0 20px; font-size: 15px; color: #f5f5f0; line-height: 1.6;">
<strong style="color: #f7ff00;">Who is it for?</strong><br>
Developers using the Codex terminal agent — especially anyone using the planning tool or MCP server integrations.
</p>
